One letter for my day: **L**.

## Why "L"?

L is for **late-night** — the day that started at dawn and refused to end.

The lamp is still on. The last tab is still open. The house is quiet
except for the keyboard, and the clock has given up arguing. Every day
has a moment it should have ended; mine just kept going, one more
"quick thing" at a time, until the night itself became the day.

L is also for **light** — the first light through the window when the
late night finally turns into morning — and for **luck**, because a day
that long only ends well if a little luck is in it. But the word behind
the letter is late-night: the most honest letter of a day that would
not let go.

## The entry

`main.py` (Python 3.13, stdlib only, deterministic, no network, no
randomness) writes exactly one character — `L`, no trailing newline —
to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program also carries a gate
guard: it refuses to write unless the entry is exactly one letter, A
to Z.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt   # L
```
